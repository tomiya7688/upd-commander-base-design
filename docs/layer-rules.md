# Layer Rules

## UI Layer

UI Layer は UI フレームワーク依存を許容する層です。

### 主な責務

- キーボード、マウス、ゲームパッド等の入力受付
- 画面遷移
- 描画
- Process Layer から返却された値の表示形式への変換
- UI上の状態管理

### 禁止事項

- ゲームルールそのものの計算
- Data Layer への直接アクセス
- Process Layer の Processing を直接呼ぶこと

## Process Layer

Process Layer はアプリケーションやゲームの意味上の処理を担当します。

### 主な責務

- ゲームロジック
- 数値計算
- ルール判定
- 状態遷移
- 必要データの要求
- 処理結果の生成

### 禁止事項

- pygame 等の UI フレームワークへの依存
- 表示色、座標、フォント等のUI表現判断
- Data Layer の Processing への直接アクセス

## Data Layer

Data Layer はデータの取得・保存・整形を担当します。

### 主な責務

- ファイル読み書き
- データベースアクセス
- 設定値読み込み
- シリアライズ / デシリアライズ
- 保存形式から利用形式への整形

### 禁止事項

- UI表示判断
- ゲームルール判断
- Process Layer の Processing を呼び出すこと

## 共通ルール

- 1ファイル1責務を基本とする。
- 1関数1処理を基本とする。
- Commander に実処理を書かない。
- Messenger に実処理を書かない。
- 層を越える通信は Messenger を経由する。
- 実処理が肥大化した場合は責務単位で分割する。
